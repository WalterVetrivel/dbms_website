What is SQL?

Definition

SQL (Structured Query Language) is the standard language for defining, querying, changing and controlling data in a relational database.

SQL is declarative (non-procedural). You say what data you want, not how to find it. The DBMS works out the steps.

SQL 
SELECT name FROM student WHERE city = 'Salem';

This one line says “give me the names of students from Salem”. It does not say which file to open or which index to use.

Purpose of SQL

  • Create and change the structure of tables (schema).
  • Insert, update, delete and retrieve data.
  • Declare integrity constraints and views.
  • Control who can access the data, and group changes into transactions.
  • Give one common language that works on MySQL, Oracle, SQL Server, PostgreSQL and others.

A short history

  • 1970: E. F. Codd publishes the relational model.
  • Mid-1970s: IBM builds System R and its language SEQUEL (Structured English Query Language), later renamed SQL.
  • 1979: Oracle releases the first commercial SQL database.
  • 1986: ANSI and ISO publish the first SQL standard (SQL-86).
  • Later standards: SQL-92, SQL:1999 (triggers, recursive queries), SQL:2003 (XML), SQL:2016 (JSON), and SQL:2023.

Every product follows the standard closely, but each adds its own features. On this site, all SQL runs on MySQL 8.4 unless the label says otherwise.

Parts of SQL

SQL commands are grouped by what they do. The four main groups are DDL, DML, DCL and TCL.

The main parts of SQL
PartPurposeCommands
DDL: Data Definition LanguageDefine, change and delete the schema (tables, views, indexes)CREATE, ALTER, DROP, TRUNCATE, RENAME
DML: Data Manipulation LanguageInsert, change, delete and retrieve the dataINSERT, UPDATE, DELETE, SELECT
DCL: Data Control LanguageGive and take away access rightsGRANT, REVOKE
TCL: Transaction Control LanguageMark the start and end of transactionsCOMMIT, ROLLBACK, SAVEPOINT
MySQL 
CREATE TABLE student (roll_no INT PRIMARY KEY, name VARCHAR(30), city VARCHAR(20));  -- DDL
INSERT INTO student VALUES (1, 'Anitha', 'Salem');                                    -- DML
SELECT name FROM student WHERE city = 'Salem';                                        -- DML (query)
START TRANSACTION;                                                                     -- TCL
UPDATE student SET city = 'Erode' WHERE roll_no = 1;                                  -- DML
ROLLBACK;                                                                              -- TCL: undo the update

The textbook also lists these parts of the language:

  • Integrity: DDL commands that declare constraints the data must satisfy (see Constraints).
  • View definition: DDL commands that define views, such as CREATE VIEW.
  • Transaction control: commands for the start and end of transactions (TCL).
  • Embedded SQL and dynamic SQL: how SQL statements are placed inside programs written in C, C++, Java or Python.
  • Authorization: commands that give access rights to relations and views (DCL).

Some books also call SELECT a separate part, DQL (Data Query Language). The textbook counts it as DML.

Basic data types

Each column has a data type. It decides which values the column can hold, how much space each value takes, and which operations make sense (you can add numbers, but not names).

CHAR and VARCHAR compared

  • CHAR(10) always uses 10 characters. 'Ram' is stored as 'Ram' plus 7 spaces. Use it when every value has the same length, such as a PIN code.
  • VARCHAR(10) uses only as much space as the value needs, up to 10. Use it for names and addresses.

Reading DECIMAL(p, d)

DECIMAL(5,2) holds 5 digits in all, 2 after the point. So the largest value is 999.99. NUMERIC(3,1) allows 44.5 but not 444.5, because 444.5 needs 4 digits.

Common mistake

Some notes say that numeric(3,2) allows 333.11. It does not. Three digits in all, with two after the point, gives at most 9.99. Count all the digits for p, not only those before the point.

Exam tip

Use DECIMAL, not FLOAT, for money. FLOAT stores an approximation, so 0.1 + 0.2 may not be exactly 0.3.

Writing SQL: basic rules

  • Keywords such as SELECT are not case-sensitive. We write them in capitals so they stand out.
  • Each statement ends with a semicolon (;).
  • Text and date values go in single quotes: 'Salem', '2026-10-08'. Numbers do not.
  • A comment starts with -- (two hyphens and a space) and runs to the end of the line.
  • A statement can span many lines. Spaces and line breaks are only for readability.

In real life

Behind every app screen

When you open your order history on a shopping app, the server runs a SELECT. When you place an order, it runs an INSERT inside a transaction that ends with COMMIT.

Data analyst jobs

SQL is one of the most asked skills in placement tests for software and analyst roles, because nearly every company keeps its data in a relational database.

Key points

  • SQL is the standard, declarative language of relational databases.
  • It began as SEQUEL at IBM in the 1970s; the first ANSI standard was SQL-86.
  • DDL defines the schema: CREATE, ALTER, DROP, TRUNCATE, RENAME.
  • DML works on the data: INSERT, UPDATE, DELETE, SELECT.
  • DCL controls access (GRANT, REVOKE); TCL controls transactions (COMMIT, ROLLBACK, SAVEPOINT).
  • CHAR(n) is fixed length; VARCHAR(n) is variable length.
  • DECIMAL(p, d): p digits in all, d after the decimal point.
