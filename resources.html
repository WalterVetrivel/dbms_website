Software for the labs

The lab exercises use MySQL 8.4 LTS. Exercise 10 uses MongoDB.

  • MySQL Community Server 8.4 LTS (opens in a new tab): the database server
  • MySQL Workbench (opens in a new tab): a program to write and run SQL
  • MySQL 8.4 Reference Manual (opens in a new tab): the full guide to every SQL statement
  • MongoDB Community Server (opens in a new tab): the document database for Exercise 10
  • MongoDB Shell (mongosh) (opens in a new tab): the command line tool for MongoDB
