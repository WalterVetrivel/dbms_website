Aim

Aim

To write a C program to implement B+ tree.

Read these topics first

You need a C compiler: GCC (through MinGW or Code::Blocks on Windows) or any online C compiler.

Steps

The record describes six steps. Each one becomes a function.

  1. Create a node (create_node): allocate memory and set whether it is a leaf. Set the number of keys to 0, and set every child pointer and the next pointer to NULL.
  2. Split a child (split_child): find the middle of a full child. Move the keys after it into a new node (with its children, if it is not a leaf). Then put the middle key into the parent.
  3. Insert into a non-full node (insert_non_full): in a leaf, shift larger keys right and insert. In an internal node, find the right child, split it first if it is full, then go down into it.
  4. Insert into the tree (insert): if the root is full, make a new root above it and split the old root. Then insert.
  5. Search (search): find the first key that is not smaller than the search key. If it is equal, the key is found. Otherwise, go down to the matching child, or stop at a leaf.
  6. Traverse (traverse): print every key in sorted order.

The record's program

This is the program from the record, with indentation added. Nothing else is changed.

C: record program (record.c) 
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

#define ORDER 4 // You can change the order (max keys per node = ORDER - 1)

typedef struct BPlusTreeNode {
    int keys[ORDER - 1];
    struct BPlusTreeNode* children[ORDER];
    int num_keys;
    bool is_leaf;
    struct BPlusTreeNode* next; // Only used for leaves (for range queries)
} BPlusTreeNode;

// Function to create a new node
BPlusTreeNode* create_node(bool is_leaf) {
    BPlusTreeNode* node = (BPlusTreeNode*)malloc(sizeof(BPlusTreeNode));
    node->is_leaf = is_leaf;
    node->num_keys = 0;
    node->next = NULL;
    for (int i = 0; i < ORDER; i++) {
        node->children[i] = NULL;
    }
    return node;
}

// Function to split a full child
void split_child(BPlusTreeNode* parent, int index, BPlusTreeNode* child) {
    int mid = (ORDER - 1) / 2;
    BPlusTreeNode* new_child = create_node(child->is_leaf);
    new_child->num_keys = mid;

    // Copy keys to new child
    for (int i = 0; i < mid; i++) {
        new_child->keys[i] = child->keys[i + mid + 1];
    }

    // Copy child pointers if not leaf
    if (!child->is_leaf) {
        for (int i = 0; i <= mid; i++) {
            new_child->children[i] = child->children[i + mid + 1];
        }
    }

    // Adjust original child
    child->num_keys = mid;

    // Shift parent's children and keys to the right
    for (int i = parent->num_keys; i > index; i--) {
        parent->children[i + 1] = parent->children[i];
        parent->keys[i] = parent->keys[i - 1];
    }

    parent->children[index + 1] = new_child;
    parent->keys[index] = child->keys[mid];
    parent->num_keys++;
}

// Insert key into non-full node
void insert_non_full(BPlusTreeNode* node, int key) {
    int i = node->num_keys - 1;

    if (node->is_leaf) {
        // Shift keys to the right
        while (i >= 0 && key < node->keys[i]) {
            node->keys[i + 1] = node->keys[i];
            i--;
        }
        node->keys[i + 1] = key;
        node->num_keys++;
    } else {
        while (i >= 0 && key < node->keys[i]) {
            i--;
        }
        i++;
        if (node->children[i]->num_keys == ORDER - 1) {
            split_child(node, i, node->children[i]);
            if (key > node->keys[i]) {
                i++;
            }
        }
        insert_non_full(node->children[i], key);
    }
}

// Insert into B+ Tree
void insert(BPlusTreeNode** root_ref, int key) {
    BPlusTreeNode* r = *root_ref;
    if (r->num_keys == ORDER - 1) {
        BPlusTreeNode* s = create_node(false);
        *root_ref = s;
        s->children[0] = r;
        split_child(s, 0, r);
        insert_non_full(s, key);
    } else {
        insert_non_full(r, key);
    }
}

// Search key in B+ Tree
bool search(BPlusTreeNode* node, int key) {
    int i = 0;
    while (i < node->num_keys && key > node->keys[i]) {
        i++;
    }
    if (i < node->num_keys && key == node->keys[i]) {
        return true;
    }
    if (node->is_leaf) {
        return false;
    }
    return search(node->children[i], key);
}

// Traverse the tree in order
void traverse(BPlusTreeNode* node) {
    int i;
    for (i = 0; i < node->num_keys; i++) {
        if (!node->is_leaf) {
            traverse(node->children[i]);
        }
        printf("%d ", node->keys[i]);
    }
    if (!node->is_leaf) {
        traverse(node->children[i]);
    }
}

// Free memory (optional utility)
void free_tree(BPlusTreeNode* node) {
    if (node == NULL) return;
    if (!node->is_leaf) {
        for (int i = 0; i <= node->num_keys; i++) {
            free_tree(node->children[i]);
        }
    }
    free(node);
}

// Driver code
int main() {
    BPlusTreeNode* root = create_node(true);
    int keys[] = {10, 20, 5, 6, 12, 30, 7, 17};
    int n = sizeof(keys) / sizeof(keys[0]);

    for (int i = 0; i < n; i++) {
        insert(&root, keys[i]);
    }

    printf("B+ Tree Traversal:\n");
    traverse(root);
    printf("\n");

    int search_key = 6;
    if (search(root, search_key)) {
        printf("Key %d found in B+ Tree.\n", search_key);
    } else {
        printf("Key %d NOT found in B+ Tree.\n", search_key);
    }

    free_tree(root);
    return 0;
}

Function by function

The node structure

#define ORDER 4
The order: the largest number of children (pointers) a node can have. A node holds at most ORDER − 1 = 3 keys. In the notes this number is called n.
int keys[ORDER - 1];
Room for 3 keys, kept in sorted order.
struct BPlusTreeNode* children[ORDER];
Room for 4 child pointers. A node with k keys uses k + 1 of them.
int num_keys; bool is_leaf;
How many keys are in use, and whether the node is a leaf. bool needs <stdbool.h>.
struct BPlusTreeNode* next;
Meant to link each leaf to the next leaf, for range queries. (The program never sets it; see below.)

create_node(is_leaf)

malloc(sizeof(BPlusTreeNode))
Gets memory for one node from the heap.
node->num_keys = 0; node->next = NULL;
A new node is empty and not linked to anything.
for (...) node->children[i] = NULL;
Every child pointer starts as NULL, so the program never follows a garbage address.

split_child(parent, index, child)

Called only when child is full (3 keys). With ORDER 4, mid = (4 − 1) / 2 = 1.

new_child = create_node(child->is_leaf); new_child->num_keys = mid;
A new right sibling at the same level, which will hold 1 key.
new_child->keys[i] = child->keys[i + mid + 1];
Copies the keys after the middle one (here only keys[2]) into the new node.
new_child->children[i] = child->children[i + mid + 1];
For an internal node, the matching child pointers move too.
child->num_keys = mid;
The old node keeps only keys[0]. Keys[1] (the middle) and keys[2] are no longer counted.
for (i = parent->num_keys; i > index; i--) ...
Shifts the parent's keys and pointers one place right to make a gap at index.
parent->children[index + 1] = new_child; parent->keys[index] = child->keys[mid];
Puts the new node to the right of the old one, and moves the middle key up into the parent.

Example: a full leaf [5 10 20] splits into [5] and [20], and 10 goes up to the parent.

insert_non_full(node, key)

if (node->is_leaf) { while (i >= 0 && key < node->keys[i]) ... }
In a leaf: walk from the last key backwards, shifting each larger key one place right, then drop the new key into the gap. This is one step of insertion sort.
else { while (...) i--; i++; }
In an internal node: find which child the key belongs under.
if (node->children[i]->num_keys == ORDER - 1) split_child(...)
If that child is full, split it before going down. Then a split never has to travel back up.
if (key > node->keys[i]) i++;
After the split, the key that moved up decides whether to go into the left or the right half.
insert_non_full(node->children[i], key);
Recursion: repeat one level down, until a leaf is reached.

insert(root_ref, key)

BPlusTreeNode** root_ref
A pointer to the root pointer, because the root can change.
if (r->num_keys == ORDER - 1)
The root is full. Make a new empty root s, put the old root under it as child 0, and split the old root. The middle key moves up into s. This is the only way the tree grows taller, so every leaf stays at the same depth.
else insert_non_full(r, key);
The root has room, so insert normally.

search(node, key)

while (i < node->num_keys && key > node->keys[i]) i++;
Skip the keys smaller than the search key.
if (... key == node->keys[i]) return true;
Found in this node, even if it is an internal node.
if (node->is_leaf) return false;
A leaf with no match: the key is not in the tree.
return search(node->children[i], key);
Otherwise go down to child i and repeat. The work is one node per level, so search takes O(log n) steps.

traverse(node) and free_tree(node)

traverse
An in-order walk: visit child 0, print key 0, visit child 1, print key 1, and so on, then the last child. Keys come out sorted.
free_tree
Frees the children first and then the node itself (a post-order walk), so no memory is leaked.

main()

BPlusTreeNode* root = create_node(true);
An empty tree is a single empty leaf.
int n = sizeof(keys) / sizeof(keys[0]);
The number of keys in the array: 32 bytes ÷ 4 bytes = 8.
insert(&root, keys[i]);
Inserts 10, 20, 5, 6, 12, 30, 7 and 17 in that order. &root lets insert change the root.

Is it really a B+ tree?

Look at the final tree from the trace. 10 and 20 are in the root, but not in any leaf. A B+ tree keeps every key in a leaf and links the leaves in a chain. So the record's program actually builds a B tree.

What a B+ tree needs, and what the record's program does
B+ tree ruleRecord program
When a leaf splits, a copy of the middle key goes up, and the key stays in the leaf.The middle key moves up and leaves the leaf (B tree style).
Every key is in a leaf; internal nodes hold only guide keys.10 and 20 are only in the root.
Leaves are linked by next pointers.next is set to NULL and never changed.
Search always ends at a leaf.Search can stop at an internal node.
A second problem: “You can change the order”

The comment on ORDER is true only for even values. With ORDER 5, mid is 2 and split_child copies keys[4], which is past the end of the 4-key array. The program then prints 5 6 7 10 20 0 12 30 0 17, with stray zeros and keys out of order. ORDER 3 crashes.

For the lab exam, write the record's program (it compiles and gives the expected output). For the viva, be ready to say how a B+ tree differs. The next section shows the changes.

A true B+ tree version

This version follows the B+ tree rules from the B+ Tree Index Files page and works for any ORDER from 3 up. It builds exactly the same trees as the visualizer below. The struct and create_node are the same as the record's, except for one spare key and pointer slot used while a node is splitting.

C: B+ tree (bplus.c) 
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

#define ORDER 4 // n: the most pointers in a node, so a node holds at most ORDER - 1 keys

typedef struct BPlusTreeNode {
    int keys[ORDER];                         // one spare place for a key before a split
    struct BPlusTreeNode* children[ORDER + 1];
    int num_keys;
    bool is_leaf;
    struct BPlusTreeNode* next;              // leaf chain, used to read keys in order
} BPlusTreeNode;

// Make an empty node
BPlusTreeNode* create_node(bool is_leaf) {
    BPlusTreeNode* node = (BPlusTreeNode*)malloc(sizeof(BPlusTreeNode));
    node->is_leaf = is_leaf;
    node->num_keys = 0;
    node->next = NULL;
    for (int i = 0; i <= ORDER; i++) {
        node->children[i] = NULL;
    }
    return node;
}

// Split a leaf that has ORDER keys. The right half moves to a new leaf,
// and a COPY of its first key goes up to the parent.
BPlusTreeNode* split_leaf(BPlusTreeNode* leaf, int* up_key) {
    int mid = leaf->num_keys / 2;
    BPlusTreeNode* right = create_node(true);
    for (int i = mid; i < leaf->num_keys; i++) {
        right->keys[right->num_keys++] = leaf->keys[i];
    }
    leaf->num_keys = mid;
    right->next = leaf->next;                // link the new leaf into the chain
    leaf->next = right;
    *up_key = right->keys[0];
    return right;
}

// Split an internal node that has ORDER keys. The middle key MOVES up.
BPlusTreeNode* split_internal(BPlusTreeNode* node, int* up_key) {
    int mid = node->num_keys / 2;
    BPlusTreeNode* right = create_node(false);
    *up_key = node->keys[mid];
    int j = 0;
    for (int i = mid + 1; i < node->num_keys; i++, j++) {
        right->keys[j] = node->keys[i];
        right->children[j] = node->children[i];
    }
    right->children[j] = node->children[node->num_keys];
    right->num_keys = j;
    node->num_keys = mid;
    return right;
}

// Insert key below node. If node splits, return the new right node
// and set *up_key to the key the parent must hold; otherwise return NULL.
BPlusTreeNode* insert_into(BPlusTreeNode* node, int key, int* up_key) {
    int i = node->num_keys - 1;
    if (node->is_leaf) {
        while (i >= 0 && key < node->keys[i]) {
            node->keys[i + 1] = node->keys[i];
            i--;
        }
        node->keys[i + 1] = key;
        node->num_keys++;
        if (node->num_keys < ORDER) return NULL;   // still fits
        return split_leaf(node, up_key);
    }
    while (i >= 0 && key < node->keys[i]) {
        i--;
    }
    i++;                                          // child i covers this key
    int child_up;
    BPlusTreeNode* new_child = insert_into(node->children[i], key, &child_up);
    if (new_child == NULL) return NULL;
    for (int j = node->num_keys; j > i; j--) {    // make room at position i
        node->keys[j] = node->keys[j - 1];
        node->children[j + 1] = node->children[j];
    }
    node->keys[i] = child_up;
    node->children[i + 1] = new_child;
    node->num_keys++;
    if (node->num_keys < ORDER) return NULL;
    return split_internal(node, up_key);
}

// Insert into the tree. When the root splits, a new root is made.
void insert(BPlusTreeNode** root_ref, int key) {
    int up_key;
    BPlusTreeNode* right = insert_into(*root_ref, key, &up_key);
    if (right != NULL) {
        BPlusTreeNode* s = create_node(false);
        s->keys[0] = up_key;
        s->children[0] = *root_ref;
        s->children[1] = right;
        s->num_keys = 1;
        *root_ref = s;
    }
}

// Search always goes down to a leaf: every key is stored in a leaf.
bool search(BPlusTreeNode* node, int key) {
    while (!node->is_leaf) {
        int i = 0;
        while (i < node->num_keys && key >= node->keys[i]) {
            i++;
        }
        node = node->children[i];
    }
    for (int i = 0; i < node->num_keys; i++) {
        if (node->keys[i] == key) return true;
    }
    return false;
}

// Print the keys in order by walking the leaf chain
void traverse(BPlusTreeNode* root) {
    BPlusTreeNode* leaf = root;
    while (!leaf->is_leaf) {
        leaf = leaf->children[0];
    }
    while (leaf != NULL) {
        for (int i = 0; i < leaf->num_keys; i++) {
            printf("%d ", leaf->keys[i]);
        }
        leaf = leaf->next;
    }
}

// Print the tree one node per line, children indented under their parent
void display(BPlusTreeNode* node, int level) {
    printf("%*s[", level * 4, "");
    for (int i = 0; i < node->num_keys; i++) {
        printf(i == 0 ? "%d" : " %d", node->keys[i]);
    }
    printf("]%s\n", node->is_leaf ? " leaf" : "");
    if (!node->is_leaf) {
        for (int i = 0; i <= node->num_keys; i++) {
            display(node->children[i], level + 1);
        }
    }
}

void free_tree(BPlusTreeNode* node) {
    if (!node->is_leaf) {
        for (int i = 0; i <= node->num_keys; i++) {
            free_tree(node->children[i]);
        }
    }
    free(node);
}

int main() {
    BPlusTreeNode* root = create_node(true);
    int keys[] = {10, 20, 5, 6, 12, 30, 7, 17};
    int n = sizeof(keys) / sizeof(keys[0]);
    for (int i = 0; i < n; i++) {
        insert(&root, keys[i]);
    }
    printf("B+ Tree:\n");
    display(root, 0);
    printf("Traversal: ");
    traverse(root);
    printf("\n");
    int tests[] = {6, 15};
    for (int i = 0; i < 2; i++) {
        printf("Search for %d: %s\n", tests[i], search(root, tests[i]) ? "Found" : "Not Found");
    }
    free_tree(root);
    return 0;
}
Output 
B+ Tree:
[10 20]
    [5 6 7] leaf
    [10 12 17] leaf
    [20 30] leaf
Traversal: 5 6 7 10 12 17 20 30
Search for 6: Found
Search for 15: Not Found

Now 10 and 20 are in the root and in the leaves, and the leaves are chained: [5 6 7] → [10 12 17] → [20 30]. This output also matches the record's expected output for 6 and 15.

What changed, and why

keys[ORDER], children[ORDER + 1]
One spare slot. A key is first put in its place, and then the node splits if it has ORDER keys (one too many). This “insert, then split” order is the one used in the notes and the visualizer.
split_leaf
Keeps the left half, moves the right half to a new leaf, links the new leaf into the next chain, and sends a copy of the new leaf's first key up. Nothing leaves the leaf level.
split_internal
Splits a guide node. Here the middle key moves up, as in a B tree, because internal keys are only signposts.
insert_into returns the new right node
The split is reported back up to the parent, which adds the key and pointer and may split in turn. A split at the root makes a new root in insert().
search uses key >= keys[i]
An equal key means “go right”, because the copy of a key is the first key of the right leaf. The search always ends at a leaf.
traverse follows next
Go down to the leftmost leaf, then walk the chain. This is how a B+ tree answers range queries such as “all keys from 6 to 17”.

The two trees differ in the order of the splits too. The record splits a full node on the way down, before it is needed. The B+ tree version splits a node only when it overflows. Both keep the tree balanced.

Viva questions

What is a B+ tree?

A balanced search tree used for database indexes. All keys are stored in the leaves, which are at the same depth and linked in order. Internal nodes hold only guide keys. See B+ Tree Index Files.

How is a B+ tree different from a B tree?

In a B tree each key appears once, in any node, and a search can stop at an internal node. In a B+ tree every key is in a leaf, internal keys are copies, and the leaves are linked, which makes range queries fast. See B Tree Index Files.

What does ORDER mean in the program?

The largest number of child pointers in a node. A node holds at most ORDER − 1 keys. With ORDER 4, at most 3 keys.

Why are the leaves linked?

To read keys in sorted order, or a range of keys, by moving from leaf to leaf without going back up the tree.

What happens when a node is full?

It splits into two nodes and a key goes up to the parent. If the root splits, a new root is made and the tree grows one level taller.

What is the time complexity of search and insert?

O(log n), because the tree is balanced and each step goes down one level. With a large fan-out, even millions of keys need only 3 or 4 levels.

Why does the program take BPlusTreeNode** in insert?

When the root splits, the root pointer in main must change to the new root. Passing its address lets insert change it.
