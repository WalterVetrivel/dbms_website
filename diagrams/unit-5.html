One student, two models

The same student as a table row and as a JSON document.

SQL (MySQL 8.4) 
CREATE TABLE student (
  roll_no INT PRIMARY KEY,
  name    VARCHAR(50),
  dept    CHAR(4)
);
CREATE TABLE student_phone (
  roll_no INT,
  phone   VARCHAR(15),
  PRIMARY KEY (roll_no, phone)
);
CREATE TABLE marks (
  roll_no INT,
  course  VARCHAR(30),
  marks   INT,
  PRIMARY KEY (roll_no, course)
);

-- Reading one student needs joins over three tables.
SELECT s.name, p.phone, m.course, m.marks
FROM student s
JOIN student_phone p ON p.roll_no = s.roll_no
JOIN marks m ON m.roll_no = s.roll_no
WHERE s.roll_no = 101;

  "marks": [
    { "course": "DBMS", "marks": 86 },

  ]
}

Cypher queries

Create a small graph, then find friends and friends of friends.

Cypher (Neo4j) 
CREATE (a:Person {name: 'Arun'}),
       (p:Person {name: 'Priya'}),
       (k:Person {name: 'Kavin'}),
       (s:City {name: 'Salem'}),
       (e:City {name: 'Erode'}),
       (a)-[:KNOWS {since: 2023}]->(p),
       (p)-[:KNOWS]->(k),
       (a)-[:LIVES_IN]->(s),
       (p)-[:LIVES_IN]->(s),
       (k)-[:LIVES_IN]->(e);
Cypher (Neo4j) 
MATCH (a:Person {name: 'Arun'})-[:KNOWS]->(f:Person)
RETURN f.name;            -- Priya
Cypher (Neo4j) 
MATCH (a:Person {name: 'Arun'})-[:KNOWS]->(:Person)-[:KNOWS]->(fof:Person)
WHERE NOT (a)-[:KNOWS]->(fof) AND fof <> a
RETURN fof.name;          -- Kavin

Roles in MySQL

Create roles, build the hierarchy and grant a role to a user.

SQL (MySQL 8.4) 
CREATE ROLE 'staff', 'teacher', 'hod';

GRANT SELECT ON college.timetable TO 'staff';
GRANT SELECT ON college.notices   TO 'staff';

GRANT SELECT, INSERT, UPDATE ON college.marks TO 'teacher';

GRANT UPDATE (approved) ON college.marks TO 'hod';
SQL (MySQL 8.4) 
GRANT 'staff'   TO 'teacher';   -- teacher inherits staff
GRANT 'teacher' TO 'hod';       -- hod inherits teacher (and staff)

SQL injection: always true

The input ' OR '1'='1 turns the WHERE clause into a condition that is always true.

SQL (MySQL 8.4) 
SELECT * FROM users
WHERE username = 'anitha' AND password = '' OR '1'='1'

The fix: a prepared statement

The input is sent as data, so it cannot change the query.

Java (safe) 
String sql = "SELECT * FROM users WHERE username = ? AND password = ?";

PreparedStatement ps = conn.prepareStatement(sql);
ps.setString(1, user);   // value for the 1st ?
ps.setString(2, pass);   // value for the 2nd ?

ResultSet rs = ps.executeQuery();
SQL (MySQL 8.4) 
PREPARE login FROM
  'SELECT * FROM users WHERE username = ? AND password = ?';

SET @u = 'anitha', @p = ''' OR ''1''=''1';
EXECUTE login USING @u, @p;     -- no rows: the attack fails

DEALLOCATE PREPARE login;
