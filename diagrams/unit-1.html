Referential integrity with a foreign key

A parent table, a child table and the FOREIGN KEY that links them.

MySQL 
CREATE TABLE customer (
  cust_id CHAR(3) PRIMARY KEY,
  name    VARCHAR(30)
);

CREATE TABLE orders (
  order_id INT PRIMARY KEY,
  cust_id  CHAR(3),
  amount   DECIMAL(10,2),
  FOREIGN KEY (cust_id) REFERENCES customer (cust_id)
    ON DELETE CASCADE
    ON UPDATE CASCADE
);

The SELECT-FROM-WHERE structure

The basic form of an SQL query and the relational algebra it stands for.

Syntax 
SELECT [DISTINCT] A1, A2, ..., An     -- target list: the columns you want
FROM   r1, r2, ..., rm               -- relation list: the tables to read
WHERE  P;                            -- qualification: the condition rows must meet
Relational algebra 
π A1, A2, ..., An (σ P (r1 × r2 × ... × rm))

From 1.11 Basic Structure of SQL Queries: The SELECT-FROM-WHERE structure

A query on two tables

The same question written with a WHERE condition and with INNER JOIN.

SQL 
SELECT student.name, department.hod
FROM student, department
WHERE student.dept = department.dept
  AND student.city = 'Salem';
SQL 
SELECT s.name, d.hod
FROM student AS s
INNER JOIN department AS d ON s.dept = d.dept
WHERE s.city = 'Salem';

DDL and DML together

Create a table, then insert, update, delete and select rows.

MySQL 
-- DDL: define the structure
CREATE TABLE student (
  roll_no INT PRIMARY KEY,
  name    VARCHAR(30) NOT NULL,
  dept    CHAR(4)
);
ALTER TABLE student ADD marks INT CHECK (marks BETWEEN 0 AND 100);

-- DML: work on the data
INSERT INTO student VALUES
  (1, 'Anitha', 'CSE', 88),
  (2, 'Bala',   'ECE', 72),
  (3, 'Charan', 'CSE', 65),
  (4, 'Divya',  'MECH', 91);
UPDATE student SET marks = 70 WHERE roll_no = 3;
DELETE FROM student WHERE dept = 'MECH';
SELECT name, marks FROM student WHERE dept = 'CSE' ORDER BY marks DESC;

Count the columns and rows of the Staff table, and name its parts.

Solution
  1. Number of columns = 6.
  2. Number of tuples = 3.
  3. Attributes: StaffID, Name, Sex, Designation, Salary and DOJ (date of joining).
  4. Degree = number of columns = 6.
